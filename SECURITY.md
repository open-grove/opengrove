# Security policy

## Supported versions

Security fixes are made for the latest released version. Older releases may be
asked to upgrade before a fix is provided.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a
public issue for an unpatched vulnerability, credential, private user data, or
exploit instructions.

Include the affected version, environment, reproduction steps, expected impact,
and any suggested mitigation. Maintainers will acknowledge a complete report,
coordinate validation and remediation, and credit reporters when requested and
safe to do so.

If private vulnerability reporting is not yet enabled, contact the repository
owner privately and wait for a secure channel before sending sensitive details.
