# Release notes

Historical release notes are available through GitHub Releases and
`CHANGELOG.md`.

During release preparation, add paired `vX.Y.Z.md` and `vX.Y.Z.zh-CN.md` files
here. Each file has exactly two level-two sections: user-facing Product Updates
and Technical Improvements. The release workflow validates and combines the
complete files into the GitHub Release body, while desktop update metadata uses
only the localized Product Updates section. See the
[release process](../development/RELEASE_PROCESS.md) for the complete-range
review and user-confirmation workflow.
