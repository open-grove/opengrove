# OpenGrove v0.7.0

[English](https://github.com/open-grove/opengrove/blob/v0.7.0/docs/releases/v0.7.0.md)

## 产品更新

- 手机端与窄屏适配：优化手机浏览器和窄窗口下的使用体验，采用抽屉式导航，保留各面板的切换状态，并改进触控拖动。桌面导航栏同时支持调整宽度、图标模式和隐藏，改进未读提示、间距以及 App 名称和图标的本地化显示。
- 更可靠的文件编辑：检测外部修改，避免保存时直接覆盖新内容；遇到冲突可比较差异、处理后保存或放弃草稿。未保存草稿可在页面切换和刷新后恢复。
- 更清楚的运行与审批状态：减少长任务因统一计时限制被中断的情况，区分拒绝单次操作、停止任务和运行环境中断。完整重启后无法续接的 Routine 审批会明确显示失败且结果未知，需要重新运行；有效审批可在热重载后继续。
- 模型与本地工具接入：扩展 Gemini、DeepSeek 的模型发现及模型限制信息，改进 Pi 的模型协议选择，接入原生文件和命令工具。改善 Claude 登录、Kimi 安装发现和 Windows Codex 桌面安装发现，减少安装后仍显示不可用的情况。
- 更稳健的账号连接：云端连接短暂异常时保留已有配置并重试，取消一个任务不会中断其他任务的凭据恢复。托管 Web 会话失效后会返回登录入口，减少页面停留在无法操作的状态。
- 独立的更新体验：未登录也可检查客户端更新；检查更新不再消耗会话刷新凭据。已安装 App 有独立的自动更新设置和检查流程，桌面窗口关闭后仍可检查。更新说明支持中英文显示。
- 更清楚的存储管理：新增分类用量统计和清理入口，协调清理与正在进行的操作，保护下载中的安装包。改进旧版 App 目录迁移和异常退出后的状态锁恢复，保留 App 工作区中的用户数据。
- 远程 Agent 协作：管理员可连接受信任的 Agent 节点，将远程 Agent 加入联系人，通过私聊或群聊中的提及和引用回复发起任务，并查看进度、恢复连接或重试。当前支持文本消息；群聊仅发送当前消息及显式引用内容。停止操作会区分本地停止等待与远端确认取消。

## 技术改进

- 统一 Host 操作契约、Client CLI 与 OpenAPI，生成的外部客户端与服务端共享接口定义。App 发布 CLI 复用统一认证，覆盖准备、发布、状态查询、恢复和应用已发布版本。
- 文件写入采用显式版本前置条件：缺少 expectedRevision 返回 428，版本冲突返回 409，并区分新建文件与更新已有文件。文件编辑器以此协调本地草稿、磁盘内容与冲突处理。
- 统一 Run 生命周期为 RunRecord.lifecycle.taskState，补充旧记录迁移和查询兼容。审批和提问增加 canceled 状态及系统原因，避免将传输错误、运行环境丢失或待确认取消误记为正常完成。
- 升级 Claude Agent SDK、Pi 和 Electron 及相关依赖，调整原生会话、工具、取消和模型元数据的适配。Pi 升级后保留旧原生会话文件，但不导入其历史来续接新会话；需要在新会话中继续工作。
- 远程协作接入 Agent Router SDK，按当前登录管理员和每次运行隔离授权，远程凭据仅保存在内存中。该路径不赋予远程 Agent 本地 Routine 或委派执行权限。
- 加强 App 版本快照、激活与恢复的状态管理，协调存储维护和客户端安装包缓存。使用操作系统持有的锁识别正在运行的实例，减少异常退出遗留锁造成的启动阻塞。
- 发布流程采用中英文发布说明和 schema v3 门禁回执，绑定候选提交与制品摘要，分离候选构建、GitHub Release 定稿、登记和上线。首个公开版本使用固定的真实 0.6.5 安装包验证升级路径；受限测试部署另支持团队 token 准入。
