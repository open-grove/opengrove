# OpenGrove v0.6.6

[English](https://github.com/open-grove/opengrove/blob/v0.6.6/docs/releases/v0.6.6.md)

OpenGrove v0.6.6 将可替换的 Store App 程序与用户持有的 Workspace 分离，并为公开仓建立经过审查的贡献流程与首次发布路径。

## 主要变化

### 1. Store App 程序迁移经过复制校验并且可以恢复

可替换的 Store App 程序会独立于持久用户 Workspace 进行迁移。迁移会在启用前校验复制出的程序代际，保留旧数据用于恢复，回滚未完成的变更，并且绝不阻塞 OpenGrove 启动。诊断导出会记录布局与迁移状态，但不会包含 Workspace 内容。

### 2. 公开 PR 与桌面最终化具有明确的信任边界

公开 PR 必须由 CODEOWNERS 中列出的仓库管理员审批。桌面最终化现在使用受保护的 `desktop-release` environment；同时仍允许一名发版人员自行审批并完成 workflow，不要求第二位操作人参与。

### 3. 首次公开发布仍保留正常的 N-1 更新门禁

由于新公开仓没有更早的 GitHub Release，`v0.6.6` 候选可以使用一次经过固定校验和审查的引导路径，从现有 `v0.6.5` 正式安装包验证升级。其他版本以及首个公开 GitHub Release 创建之后都会拒绝这条路径；后续版本恢复使用正常的上一个 GitHub Release。

## 兼容性与迁移说明

- 本版本的 `clientReleaseNumber` 为 `10031`。
- 无需手工迁移 Workspace。Store App 布局迁移不会阻塞启动，并会保留旧来源，直到允许执行经过验证的清理。
- 首次公开发布选项只影响发版基础设施，不会改变已安装客户端行为或产品认证。
- Windows 安装包在 Authenticode 证书到位前仍未签名，首次下载或启动时 Microsoft Defender SmartScreen 可能继续警告。

## 验证

- `npm run release:check`
- Store App 布局迁移、回滚、诊断与启动 Harness
- 公开发布引导 manifest、下载身份与 workflow 契约检查
- 完整三平台候选、安装后制品 smoke、updater metadata 与 v0.6.5→v0.6.6 更新门禁
