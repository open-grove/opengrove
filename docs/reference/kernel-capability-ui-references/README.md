# Kernel capability UI policy

The machine-checkable source of truth is
[`web/src/runtime/kernel-capability-ui-policy.ts`](../../../web/src/runtime/kernel-capability-ui-policy.ts).
It declares which standard
Kernel capabilities are user-facing, where they appear, and whether the UI is
gated by the runtime capability report.

See the [Kernel integration guide](../KERNEL_INTEGRATION.md) for adapter and
capability verification requirements.

Visual QA screenshots and local comparison artifacts are intentionally kept
outside the repository.
